# Assets do Jogo

Os sprites atuais sao carregados pelo arquivo `assets.go` dessa pasta usando `go:embed`. Ao compilar o jogo, as imagens entram e nao precisam ser procuradas por caminho relativo durante a execucao.

## Arquivos usados

- Jogador: `player.png`
- Tiro: `laser.png`
- Meteoros/inimigos: `meteors/*.png`
- Estrelas de fundo: `stars/*.png`
- Planetas de fundo: `planets/*.png`
